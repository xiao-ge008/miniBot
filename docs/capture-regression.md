# 截图兼容性回归清单

## 实现范围

- 截图使用独立会话状态，重复热键不会在抓图/解码时重入。
- 只有本次截图解码成功才显示遮罩；取消、加载失败及超时都会清理帧和负载。
- 旧 ready、close、reset 和帧读取请求不能影响下一轮截图。
- 不在截图阶段预热模型，也不在 2.5 秒后重复激活窗口。
- Windows 默认保留系统光标，异常机器按 F8 或点击右上角切换软件光标；偏好仅保存在截图 WebView 的本地存储中。
- macOS 在捕获前检查屏幕录制权限；截图窗口使用跨 Space、全屏辅助行为。
- 不静默改截第一块显示器，不自动更改开发服务端口。

## Windows 真机

1. 普通窗口和最大化窗口下，按 Alt+Q；拖选、移动、八方向缩放、标注、双击复制、Esc/右键退出。
2. 连续截图至少十次，在抓图期间重复按热键，并在开始后 2.5 秒内持续拖动，确认不再二次抢焦点。
3. 系统缩放分别测试 100%、125%、150%、200%；混合 DPI 多屏、负坐标屏分别截图。
4. 光标冻结机器按 F8；确认软件十字随位置变化，选区工具条仍可点击，导出图片没有软件光标。
5. 软件光标模式退出/重开截图仍生效；再次按 F8 恢复系统光标。
6. 测试取色 Alt+C、聊天截图附图、录屏选区与 LocalSend，确认退出后能立即再次截图。
7. Alt+F4 关闭截图后重新触发，确认会话未残留。

## macOS 真机（本地 Windows 无法替代）

1. 未授权时触发，必须显示系统授权流程或说明，不能继续显示仅壁纸的假成功截图。
2. 系统设置授权后完全退出并重新启动，再测试普通桌面和其他应用的独立全屏 Space。
3. 测试 Safari/Chrome 全屏、多个 Space、台前调度开关，以及显示器具有单独空间开关。
4. Retina 内屏、普通外屏、混合缩放、外屏位于主屏左侧/上方分别验证。
5. 确认捕获内容与触发时屏幕一致，遮罩不切回其他桌面，Esc 退出不遗留遮罩。
