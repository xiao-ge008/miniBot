# miniBot 浏览器助手扩展程序 (Chrome Extension MV3)

适用于 Chrome、Edge、Brave、Arc 等所有 Chromium 内核浏览器的官方扩展程序。

---

## 🌟 核心功能

1. **📥 网页正文智能提纯与归档**
   - 在任意网页空白处**点击右键**，选择 **“📥 复制/保存网页到 miniBot 知识库”** 或 **“✨ AI 总结整个网页”**。
   - 自动过滤广告、导航、侧边栏和页脚，将干净正文转换为精排 Markdown 存入 miniBot 知识库（`web/` 目录）。
2. **🖼️ 图片悬浮快捷采集**
   - 鼠标悬停在网页任意大图（长宽 ≥ 120px）上，右上角自动出现 **`📥 采集入库`** 胶囊按钮。
   - 一键将原图与页面来源直接保存至本地知识库（`images/` 目录），后台自动处理防盗链。
3. **✨ 网页划词沉浸式 AI 浮窗**
   - 划选文字后，在选区旁自动弹出 **[✨ 总结] [❓ 解释] [🌐 翻译] [💾 入库] [📋 复制]**。
   - 基于 **Shadow DOM** 技术，绝不破坏宿主网页样式，也不被任何网页 CSS 污染。
   - 实时打字机流式（Streaming）接收 miniBot 本地大模型的回答。
4. **🛡️ 剪贴板静默防冲突（方案 A）**
   - 在已安装插件的网页上复制时，自动注入零宽防冲突指纹与后台静默指令。
   - 彻底解决“网页已弹 Tip，桌面 App 又同时弹 Tip”的双重打扰问题。

---

## 🚀 安装与加载步骤

1. 打开浏览器扩展管理页面：
   - **Google Chrome**：在地址栏输入 `chrome://extensions/` 并回车。
   - **Microsoft Edge**：在地址栏输入 `edge://extensions/` 并回车。
2. 开启右上角的 **“开发者模式” (Developer mode)** 开关。
3. 点击左上角的 **“加载已解压的扩展程序” (Load unpacked)**。
4. 在弹出的文件选择器中，选择本项目的 **`extension`** 目录（路径：`H:\workSpace\miniBot\extension`）。
5. 点击浏览器右上角的扩展图标，即可看到 **miniBot 网页助手**。如果 miniBot 桌面端已启动，状态将自动显示为 **“● 已连接 App”**。
